# Sprite definition files

A definition file describes every sprite in one JSON document, so registration is a
single `TKSpriteRegistry.register_all()` call instead of code per sprite. It can be
written by hand, edited in the **Sprite Definitions** bottom panel, or generated by
[the Aseprite importer](aseprite.md).

## File shape

```json
{
  "version": 2,
  "atlases": {
    "main": "res://art/atlas.png"
  },
  "sprites": [
    { "id": 0, "name": "PLAYER", "atlas": "main", "layout": "row",
      "rect": [0, 0, 16, 16], "frame_count": 4, "draw_size": [16, 16] }
  ]
}
```

| Key | Meaning |
|---|---|
| `version` | `1` or `2`. Both load; the loader always returns the v2 shape |
| `atlases` | Alias → image path. Sprites refer to the alias, so a path change is one edit |
| `sprites` | The sprite entries, conventionally in `id` order |

## Sprite entry

`id`, `atlas` and `layout` are required. An entry missing any of them is skipped with a
warning, and the rest of the file still loads.

| Key | Type | Default | Meaning |
|---|---|---|---|
| `id` | int | — | Sprite id used at run time |
| `name` | String | `SPRITE_<id>` | Human-readable name; also the re-import key |
| `atlas` | String | — | Alias from `atlases` |
| `layout` | String | — | `single` / `row` / `frames` / `rotated` / `spin` |
| `rect` | `[x, y, w, h]` | — | Source rectangle. Required by every layout except `frames` |
| `frames` | `[[x, y, w, h], ...]` | — | Explicit rectangles, for `frames` only |
| `frame_count` | int | — | Frame count for `row` and `spin` |
| `draw_size` | `[w, h]` | frame size | On-screen size |
| `original_orientation` | int | `64` | Direction the source art faces (`rotated` / `spin`) |
| `roughness` | int | `4` | Generated directions for `rotated`; `0`–`6` |
| `visual_period_dirs` | int | `256` | Directions per visual turn for `spin` |
| `durations` | `[ms, ...]` | `[]` | Per-frame display time. The library stores it; playback is yours |
| `offsets` | `[[x, y], ...]` | `[]` | Per-frame origin correction, written by trimmed Aseprite exports |
| `source_size` | `[w, h]` | `[]` | Untrimmed size |
| `pivot` | `[x, y]` | `[0, 0]` | Draw origin. Default is top-left, matching v1 |
| `tags` | `{ name: [from, to] }` | `{}` | Named frame ranges, inclusive, 0-based |
| `source` | Dictionary | `{}` | Where the entry came from. Stored, never interpreted |
| `generated` | bool | `false` | Written by importers, to spot clashes with hand edits |
| `extras` | Dictionary | `{}` | Free space for your game. Never interpreted |
| `comment` | String | — | Free note |

## Layouts

**`single`** — one frame, exactly `rect`.

**`row`** — `frame_count` frames laid out horizontally starting at `rect`. The whole
strip must fit: `x + w * frame_count` has to stay inside the atlas.

**`frames`** — every rectangle listed explicitly. Use it when frames are not evenly
spaced or not in one row.

**`rotated`** — one source image at `rect` becomes a full set of directional frames,
generated at registration time by `TKSpriteAtlasBuilder.build_rotated()`.

**`spin`** — one source image becomes an evenly spaced in-place rotation of
`frame_count` frames, for coins and pickups.

Directions are numbered 0–255 clockwise: `0` right, `64` down, `128` left, `192` up.
`roughness` controls how many are generated — `0` = 256 frames, `3` = 32, `4` = 16,
`6` = 4.

## Version 1 compatibility

A v1 file loads with no changes. After loading:

- the returned dictionary is always v2-shaped, with defaults filled in, so callers never
  branch on version;
- the original version is kept in `source_version`;
- the v1-only `native_bullet` block is moved into `extras`, and
  `save_file(path, defs, true)` writes it back as `native_bullet`.

`save_file()` omits keys that are still at their default, so loading a v1 file and saving
it again does not add noise to the diff. Key order is preserved rather than alphabetised
(`version`, `atlases`, `sprites`, and `id` before `name` inside each entry), which keeps
diffs readable.

## Validation

```gdscript
var defs: Dictionary = TKSpriteDefinitions.load_file(path)
var sizes: Dictionary = TKSpriteRegistry.get_atlas_sizes(
	TKSpriteRegistry.resolve_atlas_textures(defs["atlases"]))
for finding in TKSpriteDefinitions.validate(defs, sizes):
	print(finding)
```

`validate()` reports rectangles that leave the atlas, `durations` and `offsets` whose
length does not match the frame count, tag ranges outside the frame range, and unknown
layouts. `register_all()` runs it automatically and pushes the findings as warnings, so
this is only needed for tooling.
